# 🛒 Electronic Shop Management System

A Python-based application designed to manage the day-to-day operations of an electronic shop, including inventory handling, billing, and record management. This project focuses on structured data processing, automation, and efficient backend logic.

---

## 📌 Project Overview

The **Electronic Shop Management System** helps shop owners or staff manage electronic product records digitally instead of maintaining manual registers. It simplifies inventory tracking, billing, and data organization using Python and Pandas.

This project was developed as a practical learning exercise to apply Python programming, data handling, and basic software design concepts.

---

## ✨ Features

- 📦 Product inventory management  
- 🧾 Billing and purchase record handling  
- 📊 Data storage and processing using Pandas  
- 🔄 Add, update, and view product details  
- 🧠 Simple and modular Python logic  
- 📁 File-based data persistence  

---

### 📖 How It Works

The system loads product data from a file or dataset
User selects operations such as:
- Add product
- View inventory
- Generate bill
- Data is processed and updated using Pandas
- Updated records are saved for future use
